A research-oriented deep learning architecture combining:

* Hamiltonian neural dynamics
* Learned Riemannian metrics
* Symplectic implicit midpoint integration
* Newton–Krylov equilibrium solving
* Matrix-free Jacobian-vector products
* Batched GMRES
* Anderson acceleration
* Implicit differentiation
* Energy and Jacobian regularization

This project explores stable equilibrium-based latent dynamics with geometrically structured neural operators.

## Features

* GPU-ready PyTorch implementation
* Mixed precision compatible
* Spectral stabilization
* Adaptive damping and line search
* Reversible latent dynamics
* Research-focused modular architecture
